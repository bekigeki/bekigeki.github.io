Was wird gezählt? / Offene Fragen
  • Erfasste Schulen: Schulnummern mit mindestens einer Datei. Jede Schule zählt einmal.
  • Rückfragen notwendig: Schulen, von denen mindestens eine Datei im Status „to_check“ liegt. Teilmenge der erfassten Schulen, dort mitgezählt.
  • Erfasste Dateien: verschiedene Dateinamen je Schule, summiert.
  • Dateien mit Rückfragen: verschiedene Dateinamen im Status „to_check“.
  • Zeitverlauf: Einreichedatum = Datum im Dateinamen. Testdatum = häufigstes Testdate je Datei. Gezählt werden Dateien.
  • Auswertbare Kinder: Geschlecht bekannt, Alter bekannt (Jahr und Monat) und mindestens ein Test.
  • Offen: Eine Schule mit gemischtem Status gilt als „Rückfragen notwendig“, bis alle Dateien erledigt sind.
